# Native NBA recent postgame source receipts v2

The explicitly null native envelope has been inspected on a newly fetched
April 10 reference page: all fifteen regulation finals passed the unchanged
final status, identity, time, period-total and completeness checks. That
October observation is historical shape evidence only, never prospective
outcomes or proof of historical pregame availability.

The opt-in recent-date collector uses a frozen source protocol with its own
`benchmarks/nba_postgame_daily_v2/captures` root and v2 schemas. Original
v1 roots, default parser and exact canonical receipt replay remain intact.
Native bytes are never rewritten to activate a date override.

Both protocols share actual request and complete-response clocks, a maximum
five-minute request interval, zero-through-three-day Eastern lookback,
bounded public transport, append-only writes and exact raw/canonical replay.
Prior retained evidence and destination paths are verified before another
fetch. The default CLI is inert.

A complete regulation-final page is source evidence only. Empty days are
`EMPTY_DAY_NO_FINAL_EVIDENCE`; unsupported, mixed, live, overtime, postseason,
malformed or incomplete pages retain opaque original bytes and zero accepted
final games. One unsupported card withholds the whole page. Old historical
pages cannot be reinterpreted as current finals.

The existing NCAA/NBA source workflow captures the previous Eastern date,
replays the exact new receipt, retains its original body as an artifact, and
publishes only a validated capture. It reports capture success, page status
and supported counts separately. Its existing schedule is unchanged.
Raw capture success never certifies independent final-score agreement.

No results are enrolled, predictions graded, features backfilled, models
trained or promoted. Matching later native finals to independently observed
ESPN results and original frozen identities remains a separate review.
